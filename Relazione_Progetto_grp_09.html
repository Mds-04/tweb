3. Descrizione del sito

EventTicket è una piattaforma web dinamica dedicata alla vendita e gestione di biglietti per diverse tipologie di eventi (Musicali, Teatrali, Mostre, Convegni e Manifestazioni Letterarie). Il sito si rivolge a tre diverse tipologie di utenti:

  • Utente Pubblico / Cliente (Livello 1 e 2): Può visualizzare il catalogo degli eventi (tramite slider nella home o tramite pagina di ricerca globale o per luogo/data), aggiungere biglietti al carrello e procedere all'acquisto.
  • Organizzatore (Livello 3): Possiede una propria dashboard dalla quale può inserire nuovi eventi, modificare quelli esistenti (inclusi locandina, programma, data e prezzi), gestire la disponibilità dei biglietti e impostare politiche di sconto last-minute automatiche.
  • Amministratore (Livello 4): Ha il controllo globale sulla piattaforma tramite la sua dashboard riservata. Può creare e gestire gli account degli organizzatori, visualizzare statistiche di vendita aggregate o per singolo organizzatore, e gestire gli account dei clienti.

5. Soluzioni Adottate (Per il Docente)

Nel corso dello sviluppo sono state adottate svariate soluzioni tecnologicamente rilevanti per soddisfare i requisiti, garantire robustezza del codice e favorire l'espandibilità:

  • Architettura DRY (Don't Repeat Yourself) sulle Categorie: Abbiamo ottimizzato drasticamente il codice refactorizzando le 5 viste delle categorie eliminando la ridondanza: tutto il traffico è convogliato su un'unica rotta dinamica parametrizzata (/eventi/{slug}) che adatta i contenuti grafici e le query al database in automatico.
  • Interazioni AJAX Avanzate con jQuery: Implementazione di un sistema di autocompletamento in tempo reale per la ricerca della città. La barra interroga le API interne in modo asincrono, senza ricaricare la pagina, migliorando drasticamente la User Experience generale.
  • Generazione Dinamica degli URL per compatibilità: Tutte le action dei form fittizi via JavaScript (necessari per supportare le chiamate RESTful PUT e DELETE) sono generate usando l'helper nativo di Laravel url(). Questo assicura che il portale funzioni perfettamente anche quando ospitato in sotto-directory di server Apache remoti.
  • Protezione delle Aree Riservate con Middleware Custom: Restrizione ferrea dell'accesso alle rispettive dashboard tramite Middleware specifici (CheckOrganizer, CheckAdmin) che si integrano armoniosamente col sistema di autenticazione Laravel Breeze, bloccando alla radice tentativi di accesso non autorizzati.
  • Database Seeding Avanzato e Automazione: Configurazione di Seeder avanzati combinati all'uso di Faker per popolare rapidamente il database con decine di eventi completi, migliaia di biglietti e account di test multi-livello (amministratori, staff, clienti), permettendo di testare istantaneamente le funzionalità di aggregazione dati e i grafici di vendita.
